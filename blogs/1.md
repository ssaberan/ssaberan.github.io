# A Bizarre Way Of Evaluating Infinite Series

**Written by: Soroush Saberan**

Given a function $f$ that is infinitely differentiable around a point $a$, we can derive the Taylor expansion of $f$ around $a$ as follows:

$$f(x)=\sum_{n=0}^{\infty}\frac{f^{(n)}(a)}{n!}(x-a)^{n}$$

However, is the reverse also possible to derive? In other words, given an infinite series $S$, can we find a function $f$ such that the Taylor expansion of $f$ around some infinitely differentiable point $a$ is $S$? If this is possible, we might be able to use the resulting function to evaluate $S$.

When investigating this, I decided to use this idea to attempt to solve the famous Basel problem in a new, bizarre way. First proposed in 1650, and solved by Leonhard Euler in 1734[\*](https://en.wikipedia.org/wiki/Basel_problem), the Basel problem asks to evaluate the following:

$$\sum_{n=1}^{\infty}\frac{1}{n^{2}}$$

Lets call this infinite sum $S$. So if we treat $S$ as a Taylor expansion of some unknown function $f$, then we can write each term in $S$ as follows:

$$\frac{1}{n^{2}}=f^{(n-1)}(a)\frac{(x-a)^{n-1}}{(n-1)!} \text{ for } n \in \mathbb{N}$$

Our choice for $x$ and $a$ is arbitrary, so lets choose values that simplify the problem. If we let $x=1$ and $a=0$, we get the following:

$$\frac{1}{n^{2}}=f^{(n-1)}(0)\frac{1}{(n-1)!} \text{ for } n\in \mathbb{N}$$

Rearranging the terms to isolate $f^{(n)}(0)$ gives us:

$$f^{(n)}(0)=\frac{n!}{(n+1)^{2}} \text{ for } n\in \mathbb{N}\cup\{0\}$$

So given the requirement above, what is $f$?

If you take the Taylor expansion of $f$ centered around $x=0$, you get the following:

$$f(x)=\sum_{n=0}^{\infty}\frac{f^{(n)}(0)}{n!}x^{n}$$

Substituting for $f^{(n)}(0)=\frac{n!}{(n+1)^{2}}$ yields:

$$f(x)=\sum_{n=0}^{\infty}\frac{\frac{n!}{(n+1)^{2}}}{n!}x^{n}=\sum_{n=0}^{\infty}\frac{x^{n}}{(n+1)^{2}}$$

Now use the formula, $\sum_{n=0}^{\infty}t^{n}=\frac{1}{1-t}$. We want to manipulate the left side of this equation until it becomes $\sum_{n=0}^{\infty}\frac{x^{n}}{(n+1)^{2}}$. Then whatever is on the right side will be $f$:

$$\sum_{n=0}^{\infty}t^{n}=\frac{1}{1-t}\Rightarrow$$

$$\int_{0}^{x}\sum_{n=0}^{\infty}t^{n}dt=\int_{0}^{x}\frac{1}{1-t}dt\Rightarrow$$

$$\sum_{n=0}^{\infty}\frac{x^{n+1}}{n+1}=-\ln(1-x)\Rightarrow$$

$$\sum_{n=0}^{\infty}\frac{x^{n}}{n+1}=-\frac{\ln(1-x)}{x}\Rightarrow$$

$$\int_{0}^{x}\sum_{n=0}^{\infty}\frac{t^{n}}{n+1}dt=\int_{0}^{x}-\frac{\ln(1-t)}{t}dt\Rightarrow$$

$$\sum_{n=0}^{\infty}\frac{x^{n+1}}{(n+1)^{2}}=-\int_{0}^{x}\frac{\ln(1-t)}{t}dt\Rightarrow$$

$$\sum_{n=0}^{\infty}\frac{x^{n}}{(n+1)^{2}}=-\frac{1}{x}\int_{0}^{x}\frac{\ln(1-t)}{t}dt\Rightarrow$$

So we get that

$$f(x)=-\frac{1}{x}\int_{0}^{x}\frac{\ln(1-t)}{t}dt$$

is the value for $f$ we were looking for.

If we plug $x=1$ into $f(x)=-\frac{1}{x}\int_{0}^{x}\frac{\ln(1-t)}{t}dt$, the upper limit makes the integral improper. It still converges: as $t\to 0^{+}$ the integrand tends to $-1$, and as $t\to 1^{-}$ it behaves like $\ln(1-t)$, which is integrable. So

$$f(1)=-\int_{0}^{1}\frac{\ln(1-t)}{t}dt.$$

For each fixed $t\in(0,1)$,

$$\int_{0}^{1}\frac{1}{1-st}\,ds=\left[-\frac{\ln(1-st)}{t}\right]_{0}^{1}=-\frac{\ln(1-t)}{t}.$$

At $t=0$ both sides have the same limit, namely $1$. The integrand $1/(1-st)$ is positive on the unit square and unbounded only at the corner $(s,t)=(1,1)$, so

$$f(1)=\int_{0}^{1}\int_{0}^{1}\frac{1}{1-st}\,ds\,dt.$$

Rotate the square by

$$u=\frac{s+t}{2},\qquad v=\frac{t-s}{2}.$$

Solving for the old variables gives $s=u-v$ and $t=u+v$. The absolute value of the Jacobian is $2$, so $ds\,dt=2\,du\,dv$, and

$$1-st=1-(u^{2}-v^{2})=1-u^{2}+v^{2}.$$

The sides of the unit square map to the boundary of a new region $S$. The sides $s=0$ and $t=0$ become $v=u$ and $v=-u$ for $0\le u\le\frac{1}{2}$, and the sides $t=1$ and $s=1$ become $v=1-u$ and $v=u-1$ for $\frac{1}{2}\le u\le 1$. So $S$ is given by $0\le u\le\frac{1}{2}$ with $|v|\le u$, together with $\frac{1}{2}\le u\le 1$ with $|v|\le 1-u$. Its corners are $(0,0)$, $\left(\frac{1}{2},-\frac{1}{2}\right)$, $(1,0)$, and $\left(\frac{1}{2},\frac{1}{2}\right)$. Therefore

$$f(1)=2\iint_{S}\frac{1}{1-u^{2}+v^{2}}\,du\,dv.$$

The integrand is even in $v$, and $S$ is symmetric about $v=0$, so the contribution from $v<0$ equals the contribution from $v>0$:

$$f(1)=4\left(\int_{0}^{1/2}\int_{0}^{u}\frac{1}{1-u^{2}+v^{2}}\,dv\,du+\int_{1/2}^{1}\int_{0}^{1-u}\frac{1}{1-u^{2}+v^{2}}\,dv\,du\right).$$

The inner antiderivative is an arctangent. For $a\ge 0$ and $u\in[0,1)$,

$$\int_{0}^{a}\frac{dv}{(1-u^{2})+v^{2}}=\frac{1}{\sqrt{1-u^{2}}}\arctan\left(\frac{a}{\sqrt{1-u^{2}}}\right).$$

Take $a=u$ in the first piece and $a=1-u$ in the second:

$$
\begin{aligned}
f(1)=4\Bigg(&\int_{0}^{1/2}\frac{1}{\sqrt{1-u^{2}}}\arctan\left(\frac{u}{\sqrt{1-u^{2}}}\right)du \\
&+\int_{1/2}^{1}\frac{1}{\sqrt{1-u^{2}}}\arctan\left(\frac{1-u}{\sqrt{1-u^{2}}}\right)du\Bigg).
\end{aligned}
$$

For the first arctangent, consider the right triangle with opposite side $u$ and adjacent side $\sqrt{1-u^{2}}$. Its hypotenuse is $1$, so the angle has sine $u$. That angle lies in $[0,\frac{\pi}{2})$, and hence

$$\arctan\left(\frac{u}{\sqrt{1-u^{2}}}\right)=\arcsin u.$$

For the second, set $\theta=\arctan\left(\frac{1-u}{\sqrt{1-u^{2}}}\right)$. Then

$$\tan^{2}\theta=\frac{(1-u)^{2}}{1-u^{2}}=\frac{(1-u)^{2}}{(1-u)(1+u)}=\frac{1-u}{1+u},$$

and so

$$\sec^{2}\theta=1+\tan^{2}\theta=\frac{2}{1+u},\qquad\cos^{2}\theta=\frac{1+u}{2}.$$

The double-angle formula gives

$$\cos 2\theta=2\cos^{2}\theta-1=u.$$

Here $2\theta$ lies in $[0,\frac{\pi}{2}]$, so $2\theta=\arccos u$ and

$$\theta=\frac{1}{2}\arccos u=\frac{\pi}{4}-\frac{1}{2}\arcsin u.$$

The integrals are now

$$f(1)=4\left(\int_{0}^{1/2}\frac{\arcsin u}{\sqrt{1-u^{2}}}\,du+\int_{1/2}^{1}\frac{\frac{\pi}{4}-\frac{1}{2}\arcsin u}{\sqrt{1-u^{2}}}\,du\right).$$

Substitute $w=\arcsin u$, so $dw=\frac{1}{\sqrt{1-u^{2}}}\,du$. The limits $u=0$, $u=\frac{1}{2}$, and $u=1$ become $w=0$, $w=\frac{\pi}{6}$, and $w=\frac{\pi}{2}$:

$$f(1)=4\left(\int_{0}^{\pi/6}w\,dw+\int_{\pi/6}^{\pi/2}\left(\frac{\pi}{4}-\frac{w}{2}\right)dw\right).$$

The first integral is

$$\int_{0}^{\pi/6}w\,dw=\frac{1}{2}\left(\frac{\pi}{6}\right)^{2}=\frac{\pi^{2}}{72}.$$

The second is

$$
\begin{aligned}
\left[\frac{\pi}{4}w-\frac{w^{2}}{4}\right]_{\pi/6}^{\pi/2}
&=\left(\frac{\pi^{2}}{8}-\frac{\pi^{2}}{16}\right)-\left(\frac{\pi^{2}}{24}-\frac{\pi^{2}}{144}\right) \\
&=\frac{\pi^{2}}{16}-\frac{5\pi^{2}}{144} \\
&=\frac{9\pi^{2}}{144}-\frac{5\pi^{2}}{144} \\
&=\frac{\pi^{2}}{36}.
\end{aligned}
$$

Therefore

$$f(1)=4\left(\frac{\pi^{2}}{72}+\frac{\pi^{2}}{36}\right)=4\cdot\frac{3\pi^{2}}{72}=\frac{\pi^{2}}{6}.$$

For $0\le x<1$ we already have $f(x)=\sum_{n=0}^{\infty}\frac{x^{n}}{(n+1)^{2}}$. Every coefficient is positive, so letting $x$ increase to $1$ passes the value of the integral on to the series:

$$\sum_{n=1}^{\infty}\frac{1}{n^{2}}=\lim_{x\to 1^{-}}f(x)=f(1)=\frac{\pi^{2}}{6}.$$

This matches the famous result by Leonhard Euler!
